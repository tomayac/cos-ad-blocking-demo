Cross-Origin Storage manager

Everything an extension can do with Cross-Origin Storage, with the crossOriginStorage, declarativeNetRequest, webRequest, browsingData, and debugger permissions.

Entries

chrome.crossOriginStorage.getEntries(), one page at a time, refreshed by onChanged. Delete an entry with removeEntry(), or block it with a crossOriginStorageHashes rule.

    Clearing site data

    chrome.browsingData.remove() with crossOriginStorage removes a site from the entries it stored and deletes the entries no other site stores.

    DevTools protocol

    Storage.getCrossOriginStorageEntries lists every entry for automation. chrome.debugger reaches it through any open web page, and Chrome shows that it is debugging while it runs.

    Log

    Rule matches, including those on Cross-Origin Storage lookups, and script requests answered from a cache, which is how a hit appears to webRequest.
